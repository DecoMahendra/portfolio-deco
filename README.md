# Portfolio Pribadi — Deco Mahendra

Website portfolio pribadi untuk personal branding sebagai Full Stack Developer.

## Isi repository ini

| Folder | Isi | Status |
|---|---|---|
| `frontend/` | Website portfolio — React + Vite + Tailwind CSS | 🚧 Dikerjakan (Phase 3/8) |
| `backend/` | Laravel API + Admin Dashboard | ⏸ Belum dimulai (Phase 9–14) |

## Cara menjalankan

```bash
cd frontend
npm install
npm run dev
```

Lalu buka `http://localhost:5173`.

Penjelasan lengkap ada di [frontend/README.md](frontend/README.md).

## Teknologi

**Frontend:** React · Vite · Tailwind CSS
**Backend (nanti):** Laravel · MySQL
